# Data

The notebook uses the **Ames, Iowa housing dataset** from the Kaggle competition
[House Prices – Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data).

Download `train.csv` and `test.csv` from that page (a free Kaggle account is required)
and place them in this folder:

```
data/train.csv   1,460 homes, 79 features + SalePrice
data/test.csv    1,459 homes, no SalePrice
```

The notebook looks for the files in `./`, `./data/`, in that order.
